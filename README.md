# Veloce Rentals

Premium Car & Bike Rentals booking application.

🌐 **Live Website Link:** [velocerentals11.vercel.app](https://velocerentals11.vercel.app/)

---

## 🛠️ Tech Stack
* **Frontend:** React (Vite), Lucide Icons, Custom Premium Glassmorphic CSS
* **Backend:** Node.js, Express, MongoDB Atlas, Mongoose
* **Notifications:** EmailJS transaction confirmations

---

## 📁 Repository Structure
* `/frontend` — React client web application
* `/backend` — Express API server and MongoDB Mongoose schemas
* `package.json` — Root monorepo configuration and script orchestrator
* `render.yaml` — Blueprint setup for automated backend deployments
